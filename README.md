# Internet Speed Test (Kotlin & Compose)

![Project Logo](logo.png)

A premium, high-performance Internet Speed Test application for Android, built with **Kotlin** and **Jetpack Compose**. Inspired by modern, minimalist designs, this app features smooth animations and a modular architecture.

## ✨ Features
- **Dynamic Speedometer**: Real-time animated gauge using Jetpack Compose Canvas.
- **Accurate Metrics**: Measures download speed and latency using OkHttp.
- **Premium UI**: Modern dark-themed design with neon gradients and glassmorphism.
- **Modular Code**: Decoupled UI components and speed test logic for easy integration.

## 🚀 Getting Started
1. **Clone the repo**:
   ```bash
   git clone <your-repo-url>
   ```
2. **Open in Android Studio**:
   Import the project and wait for Gradle to sync.
3. **Run on Device**:
   Connect your Android phone via USB and hit **Run**.

## 🛠 Technology Stack
- **Language**: Kotlin
- **UI**: Jetpack Compose
- **Networking**: OkHttp 4.12
- **Build System**: Gradle 9.4.1

## 📂 Project Structure
- `androidApp`: The main Android application module.
- `src/main/kotlin/com/example/internetspeed/ui`: Reusable UI components.
- `src/main/kotlin/com/example/internetspeed/logic`: Core speed testing logic.
